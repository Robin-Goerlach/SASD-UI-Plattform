## Translation policy

- Requirement IDs, release names, package names and ADR numbers are identical across languages.
- English code/API terminology is retained in both editions where it is part of the technical contract.
- The two editions should be changed together when normative content changes.
- In a translation ambiguity, the underlying accepted requirement/ADR and the recorded decision history must be reviewed rather than silently reconciled.

# Artefacts

This directory contains visual material that belongs with the repository but is not compiled product code.

- [`sasd-ui-platform-component-gallery.png`](sasd-ui-platform-component-gallery.png) — conceptual design target used by the root README. It is not a screenshot of completed software.
- [`architecture-diagrams/`](architecture-diagrams/) — language-specific English/German PNG renderings and Graphviz DOT sources used by the architecture documents.

Generated test screenshots do not belong here; they are ignored under dedicated visual-test output paths.

# SASD UI Component Gallery

The Gallery is the executable specification and primary visual acceptance host. The current repository contains only the minimal R0 shell. Every future component page must demonstrate applicable normal, hover, focus, disabled, read-only, busy, empty, error, High-Contrast, DPI and localisation states.

The conceptual target image is stored at [`../../artefacts/sasd-ui-platform-component-gallery.png`](../../artefacts/sasd-ui-platform-component-gallery.png).
